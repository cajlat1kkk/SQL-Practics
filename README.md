# SQL Практика

Тренажёр SQLite на русском языке со 100 заданиями. В каталоге можно искать по названию, теме или номеру и фильтровать задачи по сложности и статусу решения.

## Запуск

1. Скачайте файл [sql-praktika.html](./sql-praktika.html).
2. Откройте его в браузере. Задания, учебные таблицы, оформление и SQLite встроены в HTML. Тренажёр рассчитан на работу без интернета.
3. Нажмите **«Начать практику»** или выберите задачу из каталога.

[Открыть приватную онлайн-версию](https://sql-praktika.juicychili2.chatgpt.site). Для входа нужен аккаунт ChatGPT владельца сайта.

## Как решать задачи

1. Прочитайте условие и проверьте, какие столбцы нужно вывести.
2. Откройте вкладку **«Таблицы и данные»**, чтобы посмотреть названия столбцов, типы и строки учебных таблиц.
3. Напишите запрос в редакторе. Поддерживается один запрос `SELECT`, в том числе с `WITH`.
4. Нажмите **«Проверить»** или используйте **Ctrl + Enter** на Windows и Linux, **⌘ + Enter** на macOS.
5. Если ответ отличается от ожидаемого, откройте вкладку с непройденным набором. Там видны ваш результат, ожидаемые строки и объяснение. Подсказка доступна в условии задачи.

Черновики и решённые задачи сохраняются в текущем браузере, если он разрешает локальное хранилище. У скачанного файла и сайта свой прогресс.

## Как работает проверка

Один и тот же запрос запускается на основном и двух проверочных наборах. Проверочные данные добавляют ситуации, которые легко упустить, например дубли, `NULL`, пустые группы, равные значения и даты на границах периода.

Сравниваются значения и порядок столбцов, строки и число их повторений. Имена псевдонимов могут отличаться. Порядок строк учитывается в задачах, где сортировка указана в условии.

### Пример с повторными заказами

Нажмите **«Разобрать пример»** на главной. В задаче № 1 нужно вывести уникальные имена покупателей с оплаченными заказами. В основном наборе у каждого покупателя максимум один оплаченный заказ, и простой `JOIN` проходит. В проверочном наборе у Анны три оплаты, поэтому появляются две лишние строки.

```sql
SELECT DISTINCT c.name
FROM customers AS c
JOIN orders AS o ON o.customer_id = c.id
WHERE o.status = 'paid';
```

`DISTINCT` оставляет каждое имя один раз, даже если у одного покупателя несколько оплат или у разных покупателей совпадают имена.
